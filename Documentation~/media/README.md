Gambar menggunakan lingkungan, UI, model, material, dan teks dialog yang tersedia dalam project. Panel serta model diaktifkan pada salinan scene preview untuk memperlihatkan beberapa keadaan aplikasi. Pose idle disampel dari animasi karakter, sedangkan kamera bergerak sedikit pada setiap rangkaian frame.

GIF ini merupakan preview scene yang disusun untuk dokumentasi, bukan rekaman sesi interaktif pada headset. Tidak ada audio pada format GIF. Berkas PNG dengan nama yang sama menyediakan versi statis tampilan awal.

Scene asli tidak disimpan ulang selama pengambilan gambar. Alat capture sementara telah dikeluarkan dari folder aset aplikasi setelah proses selesai.
